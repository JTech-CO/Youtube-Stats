# YouTube 채널 성장 그래프 템플릿

YouTube 스튜디오에서 내보낸 CSV(또는 ZIP)를 넣으면 구독자·조회수·시청 시간 같은 채널 지표가
시간 순서대로 움직이는 그래프로 재생됩니다. 이 폴더만 있으면 어디서든 동작하는 정적 페이지입니다.

## 쓰는 법

1. YouTube 스튜디오 → **분석** → **고급 모드**에서 기간(예: 전체 기간)과 지표를 고릅니다.
2. 오른쪽 위 **내보내기 → CSV**로 ZIP 파일을 받습니다. 기간이 길면 여러 번 나눠 받아도 됩니다.
3. `index.html`을 열고 ZIP이나 CSV 파일들을 창에 끌어다 놓습니다.

- 여러 파일(연도별, `총계.csv`·`표 데이터.csv`)을 한 번에 넣으면 날짜별로 합칩니다.
- 열 구성은 자유롭습니다. 날짜 열 하나와 숫자 열이 있으면 숫자 열마다 그래프가 하나씩 생깁니다.
- 파일은 브라우저 안에서만 처리되며 어디에도 전송되지 않습니다.
- 데이터 없이 둘러보려면 **예시 데이터로 보기**를 누르세요(가상 채널).

## 그래프 형태

제목 아래 **데이터 설정**에서 지표마다 표시 여부와 형태를 바꿀 수 있습니다(최대 9개).

| 형태 | 기간 값 | 기본으로 쓰는 지표 |
|---|---|---|
| 캔들 · 누적 | 날마다 누적한 값의 시가·고가·저가·종가 | 구독자 |
| 막대 · 합계 | 기간 합계 | 조회수, 유효 조회수, 시청 시간, 노출수 등 |
| 선 · 평균 | 기간 평균(조회수·노출수로 가중) | 평균 시청 지속 시간, 클릭률, 비율(%) 열 |

- 캔들은 상승이면 채운 초록 몸통, 하락이면 빈 빨간 몸통입니다. 변화율도 상승 ▲초록, 하락 ▼빨강입니다.
- 평균 시청 지속 시간은 시청 시간과 조회수가 함께 있으면 주·월 단위에서 `시청 시간 ÷ 조회수`로 다시 계산합니다.
- 스튜디오의 '구독자' 열은 날마다의 증감입니다. 채널 개설일 이후부터 내보냈다면 설정의 **시작값**에
  그 전까지의 구독자 수를 넣어야 실제 구독자 수가 됩니다.
- 이름에 '변화율', '대비'가 들어간 열(다른 열에서 계산한 값)은 기본으로 꺼 둡니다.

## 조작

- 그래프를 누르면 그 그래프만 크게 보고, 나머지는 반투명하게 아래로 물러납니다. 다시 누르거나 Esc로 돌아갑니다.
- 그래프 위에 마우스를 올리면 그 기간의 모든 지표를 보여 줍니다.
- 간격(일·주·월), 범위(최근 1년·전체), 속도, 날짜 막대로 재생을 조절합니다.
- 단축키: Space 재생/정지, ←/→ 하루 이동(Shift 7일), 1~9 그래프 크게 보기, Esc 전체 보기.
- 주소 끝에 `#date=2025-07-04&interval=day&range=all&focus=2`를 붙이면 그 장면으로 바로 엽니다.

## 배포 (GitHub Pages 등)

이 폴더의 내용을 저장소에 올리고 Pages를 켜면 됩니다. 외부 라이브러리·빌드 과정이 없습니다.

내 채널을 바로 보여 주는 페이지로 만들려면 `config.js`를 고칩니다.

```js
window.GROWTH_CONFIG = {
  channelName: "내 채널",
  files: ["data/총계.csv", "data/표 데이터.csv"], // 이 폴더 기준 경로. ZIP도 됩니다.
  startSubscribers: 0,
};
```

- `files`는 웹 서버에서 열 때만 불러옵니다. `index.html`을 파일로 직접 열면 끌어다 놓기로 넣으세요.
- 올린 CSV는 누구나 내려받을 수 있습니다. 공개하고 싶지 않다면 `files`를 비워 두고 방문자가 직접 넣게 하세요.

## 폴더 구성

```
index.html          화면
config.js           배포 설정
css/style.css       디자인
js/ingest.js        CSV·ZIP 읽기, 날짜별 병합, 지표 판별
js/model.js         일·주·월 집계와 변화율
js/chart.js         캔버스 그래프
js/app.js           재생, 레이아웃, 설정, 조작
sample/sample-data.js  예시(가상) 데이터
```

지원 형식: UTF-8·EUC-KR(엑셀) CSV, 쉼표·탭·세미콜론 구분, 날짜 `2024-01-31` · `2024.1.31` · `2024년 1월 31일` · `Jan 31, 2024` · `2024-01`(월별),
시간 `0:02:41`, 백분율 `5.2%`, 천 단위 쉼표. 주별·월별 데이터는 그보다 짧은 간격을 끕니다.
