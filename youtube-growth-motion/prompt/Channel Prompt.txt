# 역할
당신은 모션 디자이너 겸 크리에이티브 코더입니다. 첨부한 채널데이터_전체기간_병합.csv로 25초 데이터 모션그래픽을 만듭니다. 슬라이드쇼나 인포그래픽 나열이 아니라, 음악 박자에 맞춰 구독자 점·선·캔들·막대 오브젝트가 변형·이동하며 "0명에서 3,387명까지"를 한 문장으로 전달하는 영상이어야 합니다. 같은 저장소의 주식 캔들 스타일 그래프 페이지는 그대로 두고, 이 작품은 새 폴더에서 따로 동작합니다.

# 입력
- 주제: 한 유튜브 채널의 2017-11-26 개설부터 2026-09-27까지의 성장 기록
- 목적/타깃: 채널 성장 기록을 영상 한 편으로 보여 주는 데이터 모션그래픽 / 한국어권 시청자
- 핵심 메시지: 0명에서 시작해 60명에서 3년을 멈춰 있던 채널이, 2023년 여름 처음 터지고 2026년 다시 터져 3,387명이 됐다.
- 데이터: 첨부 CSV(일별 구독자·누적 구독자·유효 조회수·조회수·시청 시간, 3,228일)가 유일한 소스
- 마무리: "채널 성장 기록 2017—2026" 텍스트 타이틀 + 데이터 기준일
- 브랜드: 없음(직접 설계). 채널명·로고·플랫폼 공식 로고는 쓰지 않습니다.
- 언어: 헤드라인은 한국어, 마이크로 라벨은 영문 대문자

# 데이터 규칙
- 모든 수치·날짜는 첨부 CSV에서만 계산합니다. tools/build-data.mjs가 CSV를 읽어 js/data.js를 만들고, 씬은 DATA만 참조합니다.
- 합계·기간·배율처럼 파생한 값은 계산 규칙을 스토리보드 데이터 사용표에 적습니다.
- 반올림은 화면 표기에서만 하고, 원값은 라벨에 함께 둡니다(예: 헤드라인 2,410시간, 라벨 2,409.74 H).
- 차트 축은 0에서 시작합니다. 한 차트에는 한 지표만 씁니다.
- 장식용 HUD 숫자는 날짜·씬 번호·박 카운터처럼 파일이나 타임라인에서 파생된 값만 씁니다.

# 사양
- 1920×1080, 30fps, 25초, 120 BPM (1박 = 0.5초 = 15프레임)
- 1씬 = 4박(2초), 총 12씬. 12번 씬은 6박(3초)으로 남는 시간을 흡수합니다.
- 시간 계층: 씬=4박 / 핵심 이벤트=1박 / 반복 사이클=16분음표 / 몽타주 컷=8분음표
- 전환은 박 3~5프레임 전에 시작해 박에 착지합니다.

# 1단계: 스토리보드 (코드 작성 전에 출력)
1. 데이터 사용표: 화면 표기값 / 계산 규칙 / 처리 방식
2. 카피 체인: 씬당 헤드라인 1개, 최대 2줄
3. 씬 표: 번호 / 역할 / 배경 / 시그니처 모션 / 박별 이벤트(b1~b4) / 다음 씬 전환
4. 설계 결정과 이유

# 데이터→비주얼 매핑
- 누적 구독자 전체 → 01 스크럽 숫자(되감기), 08 캔들+가격표, 11 대형 숫자, 12 라인 드로잉
- 첫 60명(2017-12-29~2020-05-27) → 한 칸씩 켜지는 60칸 그리드
- 59~69명 정체 1,147일 → 스캔 헤드가 지나가는 평탄선 + 일수 카운터, 11에서 대형 숫자
- 2023년 7~9월 +479명 → 폭발한 점이 540칸 그리드로 수렴
- 2023년 8월 시청 시간 → 31일 방사형 막대 다이얼 + 스톱워치 바늘
- 2024~2025 월별 순증 → 24개 벽돌 쌓기
- 최다 조회 일(2025-07-04) → 막대 급상승 후 축 스케일 붕괴
- 2026 주간 누적 구독자 → 주식 캔들(상승 초록, 하락 빨강) + 우측 가격표
- 1,000명 단위 소요일 → 레이스 바
- 최다 구독 일 상위 5 → 부채꼴 카드 덱 + BEST DAY 도장
- 같은 데이터가 다시 나올 때는 형식을 바꿉니다.

# 디자인 시스템
- 5색: 나이트 #0C0D10 / 레코드 레드 #FF3B2F / 그로스 그린 #1CD66C / 페이퍼 #F3EFE6 / 시그널 옐로 #FFD43B, 텍스트 잉크 #0E0F12
- 캔들·변화율은 기존 페이지와 같은 규칙: 상승 초록, 하락 빨강, ▲▼ 기호 병기
- 타이포: 헤드라인 초굵은 산세리프(Pretendard Black → Noto Sans KR 900 폴백), 라벨 모노스페이스 대문자, 숫자 tabular-nums
- 상시 HUD: 크롭마크, "0N / 12 — 역할" + 12칸 진행바, "CHANNEL 2017→2026 · 120 BPM" + 4칸 박 인디케이터, 하단 2017~2026 날짜 눈금자(누적 구독자 스파크라인 포함), 헤드라인 위 영문 캡션(타이핑+커서)
- 질감: 그레인, 도면 격자(페이퍼 씬), 하프톤 점(다크 씬), 다이얼 링, 방사형 글로우
- 네온 글로우, 다색 그라데이션, 글래스 효과는 쓰지 않습니다.

# 모션 규칙
- 등장 back/spring 오버슈트, 퇴장 expo.in, 스태거 40~80ms
- 씬마다 시그니처 모션 1개, 전환 기법 중복 금지(링 버스트, 폭발→수렴 모핑, 아이리스 팽창, 스트립 셔터, 슬라이스 글리치, RGB 색수차, 모션블러 슬라이드, 하드컷을 각 1회)
- 나머지 전환은 매치 컷
- 카운터는 목표값에서 정확히 멈춘 뒤 최소 1박 유지
- 어떤 요소도 1박 이상 완전 정지 금지

# 금지
- 불릿·표 화면, 한 화면 3문장 이상, 데이터 전체 동시 노출
- 페이드만으로 된 전환, 음악과 무관한 타이밍
- 파일에 없는 수치, 가짜 텔레메트리, 플랫폼 공식 로고 재현

# 기술 요구
- index.html + css/ + js/ 분할, classic script(file://와 GitHub Pages 모두 동작)
- 1920×1080 무대 고정 후 뷰포트에 맞춰 scale
- render(t)로 모든 상태를 t에서 계산(실시간 타이머 금지, 시드 고정 난수), window.seek(t) 노출
- 오디오: WebAudio 120 BPM 트랙(킥 1·3, 클랩 2·4, 하이햇 8분음표, 씬별 서브 드론). 01 되감기 테이프 스윕, 03 모니터 비프 + 로우패스, 04 임팩트, 07 상승 스윕, 11 하이햇 16분음표, 12 마지막 히트 + 리버브 꼬리. 같은 스케줄을 OfflineAudioContext로 WAV 렌더
- 컨트롤: 재생/정지, 스크럽 바, 박 그리드 오버레이, 씬 점프
- 별도 스크립트: CDP로 t=i/30마다 seek → 캡처, ffmpeg로 WAV와 합쳐 MP4 출력

# 진행
1단계 스토리보드를 prompt/STORYBOARD.md에 남기고 2단계 구현으로 넘어갑니다. 검수는 푸시 전에 한 번 합니다.
