## 4. 설계 결정과 이유

1. **기존 페이지는 그대로**: 루트의 캔들 그래프 페이지와 `youtube-growth-template/`은 건드리지 않고, `youtube-growth-motion/` 폴더 하나에서만 동작합니다. 폴더만 떼어 다른 저장소에 넣어도 됩니다.
2. **캔들은 08에서만**: 기존 페이지의 정체성인 캔들(상승 초록 채움, 하락 빨강, ▲▼)을 "다시 터졌다" 씬에 모아 오마주로 씁니다. 나머지 씬은 모션그래픽 사전의 다른 형식을 써서 같은 차트가 반복되지 않게 했습니다.
3. **02와 04의 운(韻)**: 02의 60칸 그리드와 04의 540칸 그리드를 같은 모양으로 두어, 2년 반 걸린 60명과 석 달 만의 479명이 한눈에 비교되게 했습니다.
4. **정체 구간 정의**: "60명에서 3년"을 감으로 쓰지 않고, 60 도달일부터 밴드(59~69)를 처음 벗어난 전날까지 1,147일로 계산했습니다. 3년(1,095일)을 넘으므로 "3년을"로 씁니다.
5. **07 축 붕괴**: 평소 조회수(중앙값 54)와 39,722를 같은 축에 두면 평소 막대가 보이지 않습니다. 먼저 평소 스케일로 보여 준 뒤 축 눈금과 함께 스케일을 바꿔, 눈금을 속이지 않고 급등을 보여 줍니다.
6. **09 카피**: 1,000명 도달은 8년 5개월이라 "8년"은 과소 표기가 됩니다. "8년 넘게"로 쓰고, 막대 라벨에 3,079 DAYS · 8Y 5M을 둡니다.
7. **헤드라인 속 카운터**: 01의 "3,387 → 0", 05의 "2,410", 07의 "54 → 39,722"는 헤드라인 글자 자리에서 직접 셉니다. 숫자를 따로 한 번 더 크게 띄우지 않아 한 화면 반복을 줄였습니다.
8. **팔레트**: 기존 페이지의 차분한 다크 톤 대신 원색 배경을 씬마다 바꿔 선명하게 했습니다. 레드 배경 위 글자는 잉크(대비 5.4:1 이상), 나이트 배경 위 글자는 페이퍼를 씁니다. 네온 글로우와 다색 그라데이션은 쓰지 않았습니다.
9. **전환 8종 1회씩**: 템플릿의 8가지 전환 기법을 각각 한 번만 쓰고, 나머지 3개(03→04, 10→11, 11→12)는 매치 컷입니다.
10. **확인 절차**: 템플릿은 스토리보드 확인 뒤 구현하라고 하지만, 이번에는 푸시 전 1회 검수로 합의했으므로 스토리보드와 구현을 함께 제출합니다.
11. **분할 파일·무의존 렌더**: 요청 저장소 규칙대로 `index.html` + `css/` + `js/`로 나누고 classic script만 씁니다. MP4 렌더는 Puppeteer 대신 Node 내장 `WebSocket`으로 Chrome DevTools Protocol을 직접 호출합니다.
